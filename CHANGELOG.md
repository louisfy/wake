# Changelog

## 1.1 — English by default

- Default to English with an immediate English / Simplified Chinese switch in Settings.
- Localize status, scan reports, port diagnostics, trust prompts, menu actions, and Wake-generated launch messages.
- Preserve project metadata, launch trust, and running services when changing language.
- Lead with English GitHub docs and screenshots while retaining Simplified Chinese guides.
- Package the app as Wake.app, keeping the application ID and existing install data.

## 1.0 — First public release

- Independent source tree with MIT license, contributor guidance and publication materials.
- Empty deployment seed and explicit folder selection for first use.
- Startup entry review and persistent configuration-bound trust before first execution.
- Project dependency probes run only during reviewed startup, not status polling.
- Generic opt-in environment-variable port routing and dynamic Docker tool discovery.
- Pinned standalone Python download, SHA-256 verification and dependency license preservation.
- Public package identifier and isolated default data directory.
- Source/archive privacy checks, explicit source export, build path mapping and metadata-free ZIP packaging.

Upstream product update detection is deferred.
